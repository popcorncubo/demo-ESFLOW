# 寓管 EstateFlow Demo

繁體中文、響應式物業管理互動示範。以原生 HTML、CSS、JavaScript 製作，不需要安裝相依套件。
![Uploading 圖片.png…]()

## 操作範圍
- 營運總覽：租金、入住率、案件與待處理維修。
- 客戶專案：新增及編輯買家／租客案件，推進需求確認、帶看、合約與完成階段。
- 物業管理：編輯租客與租期、登記全額收租、更新維修。
- 文書與帳務：收租自動產生收據；手動產生收據或發票草稿；編輯示範合約與模擬簽署；各屋主零用金收支。
- 屋主入口：切換虛構屋主，查看物業、收租、維修動態、備用金及文件。

## 使用
靜態入口為 `index.html`。可直接以靜態網站服務部署此資料夾。以 2026 年 10 月的虛構資料展示；變更只保存在當前瀏覽器的 localStorage。頁尾可重設資料。

建議展示：營運總覽「城市日光」登記收款 → 文書與帳務查看收據 → 屋主入口查看林雅雯的最新動態。另可在河岸青寓更新維修並切換屋主入口查看。

## Demo 邊界
- 沒有伺服器資料庫、多裝置同步或真實登入權限。屋主切換僅是展示，不能視為存取控制。
- 未串接付款、電子發票或電子簽署；合約是欄位與操作展示，非完整可用契約。
- 一筆租金展示全額收款，不包含部分支付、退款、跨月帳期或逾期費用。
- 文書中心手動產生文件不會變更收款狀態；登記收款會自動產生收據。
- 案件完成不會自動變更入住狀態，租務資料需另行確認。
- 可透過列印對話框選擇另存 PDF，實際輸出依瀏覽器功能。

## 驗證
JavaScript 語法檢查通過；以 Node VM 測試五個頁面的產生、收租至收據與屋主動態、重複付款防護、維修同步、備用金支出上限、租期驗證、案件新增與推進、模擬簽署、屋主畫面篩選、空狀態、字串跳脫及本機儲存。

本環境未提供此純靜態網站的相容瀏覽器預覽，因此未執行視覺瀏覽器 QA。WebMCP 工具採支援偵測，缺少相容瀏覽器時不影響網站操作；本環境未完成 WebMCP 註冊與執行驗證。
